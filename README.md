# Overview
This project was made to learn and practice R. It uses a database with Gym members excercise data. It cleans the data making sure all columns are full before analyzing the data. Then most of the program is looking for any data that has correlation to show what exercise is the best. 

I wrote this to practice R, to practice analyzing data, and to practice creating graphs in R.
